# Connecting humans to computers.

We make keyboard input methods, terminals, groupware, etc.

## bada

[bada ime](https://github.com/team-mirae/bada-ime), our flagship IME is built to be open source.

Our [bada-compatible](https://github.com/team-mirae/bada-compatible) contract is dedicated
to the public domain under CC0, and any developer is free to use, and encouraged to use.

We design our input methods and products in accordance with the bada-compatible contract.
